# kzshav.com

Personal website and portfolio of Keshav Varshney.

## Features
- Minimalist nature-themed design with custom inline SVGs
- Interactive widgets (GitHub, Instagram, LinkedIn, X, dynamic IST clock)
- Interactive animations (flying birds, leaf-shaking game, fireflies)
- Fully responsive across desktop, tablet, and mobile

## Deployment
Hosted on [Vercel](https://vercel.com) under the custom domain [kzshav.com](https://kzshav.com).
